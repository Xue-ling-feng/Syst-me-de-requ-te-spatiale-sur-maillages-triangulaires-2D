# proj1

# Présentation      
Il s'agit d'un TP du cours C++ de Licence 3 Mathématiques, consacré à la manipulation de maillages en C++.            

# Objectifs du projet

1. Saisir les coordonnées d'un point et retrouver le triangle contenant ce point.
2. Saisir le numéro d'un triangle et rechercher ses triangles voisins adjacents.
3. Implémenter deux méthodes de recherche : le parcours séquentiel simple et la recherche par table de hachage.       
4. Comparer les performances d'exécution des deux algorithmes de recherche.   

## Lancement rapide
Utiliser windows + vscode + MinGW           
Étapes :        
```
git clone [adress SSH]
cd proj2026
mkdir build
cmake .. -G "MinGW Makefiles"
cmake --build .
./go.exe
```
