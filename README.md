# proj1

简介：      
这是Projet C++ L3 Math : manipulation de maillages
en C++的TP作业。      
项目目标：        
1. 输入一个点的坐标，找到包含这个点的三角形；
2. 输入一个三角形编号，找到这个三角形相邻的三角形；
3. 通过两种不同的查找方法实现他们：简单地遍历法，hashmap搜索法。       
4. 并比较这两种方法的查找效率。   

## 快速运行：
我使用的是windows系统 + vscode + MinGW编译。        
快速运行的步骤：        
```
git clone [adress SSH]
cd proj2026
mkdir build
cmake .. -G "MinGW Makefiles"
cmake --build .
./go.exe
```
